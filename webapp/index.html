Optimize routing

    
One click: Tierllama tests every local model on your hardware (speed + capability) and fills the decision tree. More models = longer scan (~40s each).

    
    

      

    
    
  


  

    
Model suggestions (live-rated pool)

    
Rates every model you can actually reach (your local hardware + cloud), then suggests per tier. Never suggests a model that can't do the job. Custom edits preserved unless you override.

Machines found on your network. Each gets a class — that's how Tierllama knows where overnight work belongs. You confirm each machine's class yourself; Tierllama never guesses.
