## The privacy boundary (Gui law, encoded)

- **On-machine:** full prompt + confidence + answer logged locally
  (`logs/clarify_ledger.jsonl`, git-ignored). Fine.
- **Exportable/shared:** ONLY distilled patterns — never prompt text. Shape:
  `{"bucket": "defer-phrase+vague-referent", "dim": "timing", "count": 27,
  "user_answered": "NOW 19/27", "proposed_rule": "..."}` — an opt-in
  `POST /api/calibration/share` endpoint ships ONLY this shape. Prompts never
  leave the machine; nothing about the user leaves the machine.
- GUI law reminder: Gui's own traffic is fair game locally; OTHER users' data
  is export-shy by default (opt-in, distilled-only, no text).

## Why it's a big deal (1st-grade)

Today, low confidence = hidden FALLBACK lane. The user never knows. Your design
makes uncertainty VISIBLE and turns it into fuel: every clarification answer is
a labeled training example we did not have before. Confidence threshold becomes
a calibration DATA COLLECTOR, not a failure state.
