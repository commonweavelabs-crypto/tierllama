# Tierllama Brand Assets

**Brand color: `#DA1417`** (sampled from the logo PSD; replaced the older
`#E4573D` Jev red everywhere in the UI on 2026-09-23).
**Wordmark:** "TIERLLAMA" — tagline "powered by Jev".
**Trademark posture:** all marks are ORIGINAL (llama pose and geometry are not
Ollama's). OLLAMA is a registered trademark of Infra Technologies, Inc.
(USPTO #98310169) — their llama is used only in the fleet list to identify the
Ollama platform itself ("connects with Ollama" usage), never as our logo.

## Design story (short)

1. Assistant's 5 hand-coded SVG concepts (stamp style, tier-bar motif) — Gui
   liked the ideas but wanted an image generator's polish
2. Gui generated V1 (red badge + white llama + "Powered by Jev!") in ChatGPT —
   approved direction, but had watermark/gradient → needed a clean rebuild
3. Assistant's blind vector trace of V1 = lumpy, rejected ("honestly looks awful")
4. Gui redrew the design in Photoshop → final head badge + fullbody, layered
   PSDs with transparency → **adopted 2026-09-23** as the official brand
5. UI unified on the logo's own red `#DA1417` (Jev card, badges, title bar)
